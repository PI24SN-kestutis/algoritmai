# Cikliniai sąrašai C++

Ši programa sukurta C++ kalba, be STL bibliotekų, ir leidžia dirbti su cikliniais vienkrypčiais ir dvikrypčiais sąrašais. Ji pateikia interaktyvų meniu, kuriuo galima atlikti įvairius veiksmus su sąrašais.

## ✅ Funkcionalumas

🟡 **Ciklinis vienkryptis sąrašas:**
- Elementų pridėjimas (su pasirinktu kiekiu)
- Įterpimas prieš arba po nurodyto elemento
- Elemento šalinimas
- Didžiausio elemento radimas
- Specialių elementų (pirmo, vidurinio ir paskutinio) pašalinimas

🔵 **Ciklinis dvikryptis sąrašas:**
- Pirmųjų 6 neigiamų skaičių **perkėlimas** iš vienkrypčio sąrašo
- Lyginių (pagal absoliučią reikšmę) sumos skaičiavimas

🟢 **Palyginimas:**
- Parodoma, kuri suma didesnė: dvikrypčio lyginių ar vienkrypčio nelyginių
- Abi sumos atvaizduojamos ekrane

## 🧠 Techniniai reikalavimai

- C++ (naudojamas `struct` ir žemos lygio rodyklės, be STL)
- `windows.h` biblioteka naudojama UTF-8 simbolių palaikymui Windows aplinkoje
- Funkcijos apsaugo vartotojo įvestį nuo neteisingų reikšmių (pvz., `char`)
