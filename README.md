# Dvikrypčio ir vienkrypčio sąrašo projektas

## Aprašymas

Šis projektas parašytas C++ kalba be STL bibliotekų.

Programa atlieka šias funkcijas:
- Leidžia vartotojui ranka įvesti skaičius į dvikryptį sąrašą (BiNode).
- Generuoja atsitiktinius skaičius ir įterpia juos į dvikryptį sąrašą.
- Atspausdina visą dvikryptį sąrašą.
- Sukuria vienkryptį sąrašą (OneNode) iš tų skaičių, kurie dvikryptyje sąraše pasikartoja.
- Atspausdina vienkryptį pasikartojančių skaičių sąrašą, sunumeruoja elementus ir nurodo pasikartojančių skaičių kiekį.

Programa turi paprastą, draugišką vartotojo sąsają su meniu.


## Paleidimas

1. Atsisižskite arba nukopijuokite šio projekto failus.
2. Atidarykite projektą savo C++ aplinkoje (pvz., Visual Studio, Code::Blocks arba tiesiog per terminalą su `g++`).
3. Kompiliuokite projektą:

```bash
g++ -o programa main.cpp
```

4. Paleiskite programą:

```bash
./programa
```

## Funkcijos

- **1 pasirinkimas**: Pridėti skaičius rankiniu būdu.
- **2 pasirinkimas**: Generuoti atsitiktinį sąrašą.
- **3 pasirinkimas**: Atspausdinti dvikryptį sąrašą.
- **4 pasirinkimas**: Sukurti pasikartojančių skaičių vienkryptį sąrašą.
- **5 pasirinkimas**: Atspausdinti vienkryptį pasikartojančių skaičių sąrašą.
- **6 pasirinkimas**: Išeiti iš programos.

## Pastabos

- Programa tinkama tik Windows sistemoms, nes naudojama `#include <windows.h>` ir `system("cls")`/`system("pause")` komandos.
- Naudojami rankiniu būdu sukurti sąrašai (be STL).
- Tinkama mokytis bazinių dvikrypčių ir vienkrypčių sąrašų veikimo principų.
